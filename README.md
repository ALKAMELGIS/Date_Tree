# Date_Tree

Date palm training samples for Syntra AI.

| | |
|---|---|
| Images | 1,078 RGB tiles, 256 × 256 px, `.tif` (not georeferenced) |
| Labels | 922 Pascal VOC `.xml` files, 9,874 boxes, one class: `palmtree` |
| Split | all in `train/`; `test/` is empty |
| Area | Al Ain, United Arab Emirates |
